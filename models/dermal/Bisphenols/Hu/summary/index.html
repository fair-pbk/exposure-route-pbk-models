    BPA_Dermal_simple-Hu-based

    Notes


    BPA (BPS; BPF, BPAF bisphenols adjustements) PBK (Hu et al. 2023): followed Hu values and BPA when creating (Human model, dermal only exp) based on approach in the paper, computations based on Hu R code Model description http://dx.doi.org/10.1016/j.scitotenv.2023.161639

    Transfer equations

    id from to equation
    _J0 AWELL AVE JSC10 * Area_exposed_skin * (1 - Area_exposed_follicle)
    _J1 AWELL AFO JFO * Area_exposed_skin * Area_exposed_follicle
    _J2 Aplasma AVE QVE * Cplasma
    _J3 AVE Aplasma QVE * (CVE / pskin)
    _J4 Aplasma AFO QFO * Cplasma
    _J5 AFO Aplasma QFO * (CFO / pskin)
    _J6 Aplasma Askin_unexp Qskin_unexp * Cplasma
    _J7 Askin_unexp Aplasma Qskin_unexp * (Askin_unexp / Vskin_unexp) / pskin
    _J8 Aplasma ARestbody Qrest * (Aplasma / Vplasma)
    _J9 ARestbody Aplasma Qrest * (ARestbody / Vrestbody) / PCRestbody
    _J10 Aplasma AUrine CLUrine * (Aplasma / Vplasma)

    ODEs

    \(\frac{d[\mathtt{AWELL}]}{dt} = - \mathit{JSC10}\cdot \mathit{Area\_exposed\_skin}\cdot (1-\mathit{Area\_exposed\_follicle}) - \mathit{JFO}\cdot \mathit{Area\_exposed\_skin}\cdot \mathit{Area\_exposed\_follicle}\)

    \(\frac{d[\mathtt{AVE}]}{dt} = \mathit{JSC10}\cdot \mathit{Area\_exposed\_skin}\cdot (1-\mathit{Area\_exposed\_follicle}) + \mathit{QVE}\cdot \mathit{Cplasma} - \mathit{QVE}\cdot \frac{\mathit{CVE}}{\mathit{pskin}}\)

    \(\frac{d[\mathtt{AFO}]}{dt} = \mathit{JFO}\cdot \mathit{Area\_exposed\_skin}\cdot \mathit{Area\_exposed\_follicle} + \mathit{QFO}\cdot \mathit{Cplasma} - \mathit{QFO}\cdot \frac{\mathit{CFO}}{\mathit{pskin}}\)

    \(\frac{d[\mathtt{Askin-unexp}]}{dt} = \mathit{Qskin_{unexp}}\cdot \mathit{Cplasma} - \frac{\mathit{Qskin_{unexp}}\cdot \frac{\mathit{Askin_{unexp}}}{\mathit{Vskin_{unexp}}}}{\mathit{pskin}}\)

    \(\frac{d[\mathtt{Aplasma}]}{dt} = - \mathit{QVE}\cdot \mathit{Cplasma} + \mathit{QVE}\cdot \frac{\mathit{CVE}}{\mathit{pskin}} - \mathit{QFO}\cdot \mathit{Cplasma} + \mathit{QFO}\cdot \frac{\mathit{CFO}}{\mathit{pskin}} - \mathit{Qskin_{unexp}}\cdot \mathit{Cplasma} + \frac{\mathit{Qskin_{unexp}}\cdot \frac{\mathit{Askin_{unexp}}}{\mathit{Vskin_{unexp}}}}{\mathit{pskin}} - \mathit{Qrest}\cdot \frac{\mathit{Aplasma}}{\mathit{Vplasma}} + \frac{\mathit{Qrest}\cdot \frac{\mathit{ARestbody}}{\mathit{Vrestbody}}}{\mathit{PCRestbody}} - \mathit{CLUrine}\cdot \frac{\mathit{Aplasma}}{\mathit{Vplasma}}\)

    \(\frac{d[\mathtt{ARestbody}]}{dt} = \mathit{Qrest}\cdot \frac{\mathit{Aplasma}}{\mathit{Vplasma}} - \frac{\mathit{Qrest}\cdot \frac{\mathit{ARestbody}}{\mathit{Vrestbody}}}{\mathit{PCRestbody}}\)

    \(\frac{d[\mathtt{AUrine}]}{dt} = \mathit{CLUrine}\cdot \frac{\mathit{Aplasma}}{\mathit{Vplasma}}\)

    Rate rules

    dCSC01/dt = D_SC * (CSC00 - 2 * CSC01 + CSC02) / pow(SC_dx, 2) + u1 * (CSC02 - CSC00) / (2 * SC_dx)

    dCSC02/dt = D_SC * (CSC01 - 2 * CSC02 + CSC03) / pow(SC_dx, 2) + u1 * (CSC03 - CSC01) / (2 * SC_dx)

    dCSC03/dt = D_SC * (CSC02 - 2 * CSC03 + CSC04) / pow(SC_dx, 2) + u1 * (CSC04 - CSC02) / (2 * SC_dx)

    dCSC04/dt = D_SC * (CSC03 - 2 * CSC04 + CSC05) / pow(SC_dx, 2) + u1 * (CSC05 - CSC03) / (2 * SC_dx)

    dCSC05/dt = D_SC * (CSC04 - 2 * CSC05 + CSC06) / pow(SC_dx, 2) + u1 * (CSC06 - CSC04) / (2 * SC_dx)

    dCSC06/dt = D_SC * (CSC05 - 2 * CSC06 + CSC07) / pow(SC_dx, 2) + u1 * (CSC07 - CSC05) / (2 * SC_dx)

    dCSC07/dt = D_SC * (CSC06 - 2 * CSC07 + CSC08) / pow(SC_dx, 2) + u1 * (CSC08 - CSC06) / (2 * SC_dx)

    dCSC08/dt = D_SC * (CSC07 - 2 * CSC08 + CSC09) / pow(SC_dx, 2) + u1 * (CSC09 - CSC07) / (2 * SC_dx)

    dCSC09/dt = D_SC * (CSC08 - 2 * CSC09 + CSC10) / pow(SC_dx, 2) + u1 * (CSC10 - CSC08) / (2 * SC_dx)

    Assignment rules

    variable assignment
    SurfaceDepot VSSD
    ExposedVE VexposedVE
    Follicle Vfollicle
    UnexposedSkin Vskin_unexp
    Plasma Vplasma
    Restbody Vrestbody
    Thickness_VE (Thickness_epidermis_finger - 185) / 100000
    Vplasma VplasmaC * BW
    Vskin VSkinC * BW
    Vbody_total VBody * BW
    Vrestbody Vbody_total - Vplasma - Vskin
    frac_exposed Area_exposed_skin / BSA
    VexposedSC Area_exposed_skin * Thickness_SC
    VexposedVE Area_exposed_skin * Thickness_VE
    Thick_follicle (388/560) * Thickness_skin_finger / 100000
    Vfollicle Area_exposed_skin * Area_exposed_follicle * Thick_follicle
    Vskin_unexp Vskin - VexposedSC - VexposedVE - Vfollicle
    VSSD Area_exposed_skin * 0.01
    QC QCC * 60
    Qskin QSkinC * QC
    Qskin_exposed Qskin * frac_exposed
    Qskin_unexp Qskin * (1 - frac_exposed)
    Qrest QC - Qskin
    QFO 0.25 * Qskin_exposed
    QVE 0.75 * Qskin_exposed
    Cplasma Aplasma / Vplasma
    CSSD AWELL / VSSD
    CVE AVE / VexposedVE
    CFO AFO / Vfollicle
    CSC00 PCSC * CSSD
    CSC10 PCSCVE * CVE
    CvVE CVE / pskin
    CvFO CFO / pskin
    JSC00 -D_SC * (CSC01 - CSC00) / SC_dx - u1 * CSC00
    JSC10 -D_SC * (CSC10 - CSC09) / SC_dx - u1 * CSC10
    JFO P_follicle * (CSSD - CFO / PCFO)
